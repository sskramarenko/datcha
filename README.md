# Дачный бот

Бот для чата «Дачные истории»: собирает выезд, ведёт стол, считает кассу.

## Как проходит выезд

1. Кто угодно пишет `/выезд` — бот предлагает восемь ближайших выходных
2. Каждый жмёт все даты, когда может (передумать можно в любой момент)
3. Когда картина ясна — кнопка **Зафиксировать дату**, побеждает дата с большинством
4. Проголосовавшие за неё автоматически попадают в «едут», остальные отмечаются кнопками
5. За 3 дня бот пингует тех, кто не отметился; накануне вечером шлёт сводку с погодой

## Команды

**Выезд:** `/выезд` · `/кто` · `/сбор 11:00` · `/отбой`

**Стол:** `/везу шарлотку` · `/стол` · `/неВезу шарлотку`
Бот ловит дубли («шарлотку уже везёт Лена») и показывает, каких категорий не хватает:
мясо и гриль, салаты, гарнир, закуски, сладкое, напитки.

**Деньги:** `/потратил 3500 мясо` · `/касса`
Делит на тех, кто отметился «еду», и показывает минимальное число переводов.

**Машины:** `/машина 3` (еду за рулём, свободно 3 места) · `/подвезите`

**Игры:** `/новаяИгра Фиеста` · `/игра` (случайная) · `/игры` (с оценками) · `/оценка Фиеста 5`

**Дача:** `/погода` (пятница-воскресенье с вердиктом «шашлык или дождь») ·
`/дом вода есть, дорога чистая` — заметка хозяина, её бот показывает накануне выезда.

## Настройка

Координаты уже прописаны: 56.003470, 38.213553 — «Поместье Сергея».
При необходимости меняются переменными окружения `DACHA_LAT`, `DACHA_LON`, `DACHA_NAME`.

Игротека предзаполнена: Уно, Шляпа, Фиеста, Свинтус, Зельеваренье, Покер, Дартс,
Это ты (PS4), Безумцы (PS4), Знание — сила (PS4). Добавить новую — `/новаяИгра Название`.

Токен: переменная `BOT_TOKEN` либо файл `token.txt` рядом с `bot.py`.

## Важно

У @BotFather отключите **Group Privacy** (`/mybots` → бот → Bot Settings → Group Privacy → Turn off),
иначе бот не увидит команды в группе.

Данные (выезд, игры, заметки) хранятся в `dacha_data.json` рядом с ботом.
